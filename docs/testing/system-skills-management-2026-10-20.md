# 系统技能管理验收（2026-10-20）

## 结果与入口

超管在“专家·技能·连接器 → 技能 → 系统技能”管理系统技能的公共上下架状态。原“公共资源管理”入口也包含这些技能。普通账号不能调用公共上下架接口。

本次补齐的两个来源：

- `octop-assistant`：通用对话运行实例由模板预置的配置助手。
- `mcporter`：旧运行环境保留下来的内置 MCP CLI 技能，当前发行目录没有它，但运行实例仍会扫描到。

## 行为

- 运行目录中发现的历史内置技能登记到系统技能目录；仅记录公开展示元数据，不复制提示词、凭据或私有技能内容。登记后即使原实例停止，超管仍可管理其上下架状态。
- 未修改的通用运行实例预置配置助手按系统技能处理，不再因存放于工作区而绕过公共下架。
- 来源识别比较当前模板内容，并兼容已核实的旧版预置文件 SHA-256；修改过的私有版本和单独创建专家中的独立副本继续保留。
- 下架会同时隐藏聊天选择器和直接详情，并更新运行时技能过滤。个人启用操作不能覆盖超管下架，重新启动实例后仍保持下架。
- 重新上架恢复公共技能可见性及调用资格；此前个人或专家单独配置的禁用仍保留。

## 自动化验收

- `make all`：4,922 项通过、233 项跳过；格式、Ruff 和严格 mypy 均通过。
- 公共资源、账号预设偏好和 i18n 针对性测试：95 项通过。
- 补充验证后，公共资源与账号预设 API：13 项通过，包含历史技能发现、别名过滤、禁用后重启、停机后的目录保留、重新上架和独立私有副本保留。
- 前端针对性 Vitest：6 项通过，包含系统技能展示、公共开关调用、服务端拒绝后状态保持，以及现有聊天技能选择器。
- 修改的前端文件 ESLint 通过；TypeScript 与前端构建通过。

## 本地浏览器验收

- 新入口中同时找到“Octop 配置助手”和“mcporter”，初始状态均为上架。
- 通过两个开关下架，刷新读取的公共设置中两项均为下架。
- 从侧栏进入空白新建任务，打开“更多工具 → 技能”，两项均不再出现，其他已安装技能仍可见。
- 返回系统技能入口重新上架；逐项比较导入前后的 `public_resources_disabled:*` 设置，所有公共上下架状态恢复到测试前原值。
- 最终页面保留在“系统技能”，搜索 `CLI`，两个开关均显示上架。
